# Clue Cards

## ▶ [Play the game](https://libyan11.github.io/clue-cards/)

https://libyan11.github.io/clue-cards/

A clue party game for 2 to 10 players, each on their own phone. English or Arabic words. Part of [Game Night](https://libyan11.github.io/).

**How to play**
- Everyone gets a different secret word, all from the same category. Only you see yours.
- Write a clue that's close to your word, without using the word itself.
- The clues come up one at a time. Guess which word each clue is about: pick from the list, or type it in the harder mode.
- A right guess scores 2. Every player who guesses your word scores you 1.

**Play with friends:** one person taps *Create a room* and shares the 4-letter code or link. The host picks the categories, rounds, clue length and timers.
